# aiproject

오늘 배운 ESP32-S3 센서, 브라우저 데이터 수집, 카메라 이미지 분류 내용을 날짜별로 정리한 저장소다.

## 학습 자료

- [today-2026-08-04 전체 정리](today-2026-08-04/)
- [브라우저 영상](today-2026-08-04/01-manim-video/)
- [Netlify 배포 페이지](https://kyonhyon1713-aiproject.netlify.app/)

`today-2026-08-04`에는 기존에 저장소에 올렸던 Arduino/BLE 문서와 Manim 영상 파일,
그리고 참고했던 `sensorTest`, 카메라 학습 리포트·데이터셋, Webppt 자료를 함께 보관했다.

환경 폴더(`.venv`, `media`, `__pycache__`, `.agents`, `.claude`)는 재현에 필요한 학습 자료가
아니라 로컬 실행 캐시이므로 저장소에는 넣지 않았다.
