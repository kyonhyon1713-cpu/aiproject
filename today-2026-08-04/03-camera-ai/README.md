# 카메라 사진 저장 폴더

ESP32-S3 Sense AP 수집기에서 촬영한 사진 ZIP을 이 폴더에 저장한다.

1. 브라우저에서 `http://192.168.4.1`을 연다.
2. 라벨을 입력한다.
3. `1장 캡처` 또는 `20장 버스트`를 사용한다.
4. 약 150장을 모은 뒤 `전체 ZIP 다운로드`를 누른다.
5. 브라우저의 저장 위치를 이 폴더로 지정하고 `xiao_dataset.zip`으로 저장한다.

20장 버스트를 8번 실행하면 160장이다. 갤러리에서 10장을 삭제한 뒤 ZIP을
다운로드하면 약 150장을 만들 수 있다. 페이지를 새로 고치면 갤러리가 비워지므로
ZIP을 먼저 다운로드한다.

접속 AP: `bkh`

비밀번호: `11112222`
